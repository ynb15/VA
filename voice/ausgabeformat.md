# Ausgabeformat — wie YNB Entwürfe bekommt

Kurze Regel, zweimal schmerzhaft gelernt. Das Zielmedium entscheidet das Format,
nicht die Gewohnheit.

## Google Docs → Code-Block

Gerenderter Markdown-Fließtext wird beim Einfügen in Google Docs zu
Zeilenumbrüchen, nicht zu Absätzen. Alles, was er in ein Doc kopiert
(Essays, Substack-Entwürfe, Notes), kommt deshalb im Code-Block.

## E-Mail und WhatsApp → normaler Fließtext

**Kein Code-Block.** Der Block erzwingt harte Zeilenumbrüche bei ~72 Zeichen,
die beim Einfügen in Gmail als echte Umbrüche landen — er muss sie dann von
Hand wieder herausnehmen.

Stattdessen: normale Absätze, durch Leerzeilen getrennt, **jeder Absatz eine
durchgehende Zeile ohne manuellen Umbruch**. Aufzählungen als echte Bullets.
Betreffzeile separat darüber, nicht im Text.
