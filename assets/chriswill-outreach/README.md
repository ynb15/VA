# Chris Williamson essay — outreach card assets

19 PNGs for the video montage in the **Wanted** chapter
("dozens of cold emails, then fifties, then hundreds").

Source: real sent and received mail, `ynb@yannick-noah.com` /
`info@yannickbernard.com`, May–Nov 2026. 402 outreach threads in total;
201 of them carry the "Man's Search for Meaning" subject line.

**No email addresses on any card.** Each outreach card shows recipient,
subject and the real first paragraph — which in every case is about the
recipient, not about the sender. That is the point: it proves none of it
was a template.
