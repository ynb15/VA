# Craig nennt das Sprichwort zweimal, erst lang, dann kurz:
#
#   UMNTU NGUMNTU NGABANYE ABANTU     (Zeile 7)
#   UMNTU NGUMNTU NGABANTU            (Zeile 8)
#
# „a person is a person through or by means of people" — seine eigene
# Uebersetzung, direkt danach.
#
# Schreibweise: isiXhosa, nicht isiZulu. Zulu waere „umuntu ngumuntu
# ngabantu" mit u nach dem m; Xhosa laesst es weg: „umntu". Craig sagt
# selbst „defined in Xhosa", also die Xhosa-Schreibweise.
#
# Wie ich es abgesichert habe — vier unabhaengige Durchlaeufe:
#   whisper medium, normal     -> "umtu ngumtu ngabania ubuntu ah ngabania
#                                 abantu" und die kurze Form GAR NICHT
#   whisper large-v3, normal   -> "umtu ngumtu ngabanya abantu /
#                                 otherwise umtu ngumtu ngabantu"
#   whisper large-v3, 0,7-fach -> wortgleich
#   whisper large-v3, 0,6-fach -> wortgleich
# Dazu die Schreibweise gegen Quellen geprueft (BU African Studies,
# SA Ubuntu Foundation, Wikipedia „Ubuntu philosophy"): beide Formen sind
# belegt, die kurze ist die bekanntere.
#
# Das heisst auch: haette ich nur einmal transkribiert, stuende auf Deinem
# Short „NGABANIA UBUNTU AH NGABANIA ABANTU" — und die kurze Form gar nicht,
# weil das Modell sie ueberhoert hat. Beides eingebrannt und nicht mehr zu
# retten.
